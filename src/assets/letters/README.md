# 3D LED Letters slideshow images

Drop the photos for the homepage "3D LED Letters" slideshow here.

- **Any number of images** (e.g. your 37) — they are picked up automatically.
- **Order = filename order.** Name them `01.jpg`, `02.jpg`, … `37.jpg` so they
  play in the order you want (zero-padded so `02` sorts before `10`).
- **Formats:** jpg, jpeg, png, webp, avif.
- **Recommended size:** 1200 × 900 px (4:3), compressed to < 250 KB each.

No code changes needed — add or remove files and rebuild.
